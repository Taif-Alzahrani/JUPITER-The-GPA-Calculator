# JUPITER-The-GPA-Calculator
“Jupiter” is an interactive platform for all students that helps students to calculate and manage their GPA easily with user-friendly interface. It provides secure environment to store grades and personal data. Students can create accounts, log in, manage subjects, view GPA and hours, select scales, set theme preferences, and print summaries.
